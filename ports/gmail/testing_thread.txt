Game Information
Title: Gmail
URL: https://github.com/Samukiniaco/oddhub

Instructions:
Ready to run in demo mode with no account and no network. For a real mailbox, generate the dependencies on a PC with fetch_deps.py and copy the site-packages folder into ports/gmail/gmail/, then set your IMAP/SMTP account in Settings.

| Button | Action |
|--|--|
| D-Pad | Move selection |
| A | Open email / activate |
| B | Back |
| X | Toggle star |
| Y | Next folder |
| L1 | Scroll up |
| R1 | Scroll down |
| L2 | On-screen keyboard |
| R2 | Delete email (asks first) |
| Start | Settings |
