# OddHub — coletânea de ports PortMaster

Projeto para portar aplicativos "não convencionais" (WhatsApp, Instagram,
Pinterest, Google, Spotify, YouTube Music, Netflix, Crunchyroll, ...) para
consoles portáteis via PortMaster, compartilhando um núcleo (`core/`).

> **Status:** em desenvolvimento. O `core/` é um esqueleto/template e ainda
> não é usável em produção. Nenhum port de app está funcional ainda. O port
> de referência é `port de ref/` (jogo CaVo), mantido como exemplo de scripts.

- Núcleo compartilhado: `core/`
- Ports: `ports/` (um por app + `oddhub` gerenciador)
- Acompanhamento: `PORTS.md`
- Arquitetura: `docs/architecture.md`

Repositório: https://github.com/Samukiniaco/oddhub.git
